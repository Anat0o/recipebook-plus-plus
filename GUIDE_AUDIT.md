# Аудит гайдов RecipeBook++

Эталон механик: Minecraft Java 26.2. Простая геометрия с меткой Bedrock оставлена только там, где схема не зависит от Java-specific правил сигнала или спавна. Большие постройки могут состоять из нескольких согласованных разрезов; ни один обязательный узел не подразумевается «за кадром».

## Как проверять

- `npm test -- --run` проверяет координаты, опоры, направления, части дверей/кроватей, допустимые блоки, сценарные ссылки, торговые пулы и редстоуновые задержки.
- `npm run build:data` собирает схемы, атлас, сущности, анимации, станции и торговлю для 26.2, 26.1.2 и 1.21.11; `npm run check:coverage` запрещает неизвестные пропуски.
- `npx tsx tools/generate-guide-smoke.ts <world>` создаёт временный datapack 26.2 из тех же координат. На чистом Java 26.2 server функция `recipebook:all` должна вывести `RECIPEBOOK_GUIDE_SMOKE_OK`.
- Браузерная проверка: открыть последний шаг схемы, нажать «Пуск», проверить сигнал/сущности, затем «Сброс»; в режиме reduced motion пользоваться кнопкой «Кадр».

## Результат smoke-проверки 26.2

14 сентября 2026 года изолированный vanilla server Java 26.2 (официальный server JAR SHA-1 `823e2250d24b3ddac457a60c92a6a941943fcd6a`, Java 25) загрузил заново сгенерированный datapack и разместил все 35 разрезов из текущих данных. Итог функции: `RECIPEBOOK_GUIDE_SMOKE_OK`. Это подтверждает существование блоков, допустимость block state и совпадение координат генератора с данными сайта. Биологическая производительность ферм (частота спавна, рост и случайность лута) не заявляется как доказанная этим коротким smoke-тестом; её сценарии в интерфейсе отделены от расчёта редстоун-сигнала.
